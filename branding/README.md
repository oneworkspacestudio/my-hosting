# Original My Hosting mark

Editable vector: `my-hosting.svg`; monochrome: `my-hosting-mono.svg`. The same
transparent, tile-free vector serves light/dark UI and favicon/launcher exports.
The upward mint publish arrow and layered indigo hosting surfaces are original
One Workspace artwork, licensed with this repository (Apache-2.0).

Exact gradient stops come from the existing One Workspace Chat/Notes icons;
Drive informed the layered silhouette and transparent footprint. Silver details
match Notes and Chat. No Netlify/Vercel/Caddy logo or third-party image was used.
See `docs/IMPLEMENTATION.md` for the comparison against those three suite apps.
